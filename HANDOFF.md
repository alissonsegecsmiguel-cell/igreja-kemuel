## 10. Como publicar um post novo

1. Primeira vez no computador: npm install --prefix scripts (instala mammoth, marked e sharp, só para desenvolvimento).
2. Copie o modelo-post.docx (ou um .md com as mesmas convenções) para textos-blog/, preencha e coloque as imagens na mesma pasta ou em textos-blog/imagens/. Confira a licença de cada imagem e registre em dados/creditos-imagens.json.
3. Converta: node scripts/converter-post.mjs textos-blog/arquivo.docx. Confira conteudo/blog/[slug].md e as imagens em assets/img/blog/[slug]/.
4. O conversor gera também capa-card-600/900/1400.webp a partir do original, sem ampliação; manter os créditos/licenças ao publicar. Informe de 2 a 4 temas no campo Temas: (separados por vírgula) do rascunho ou no array temas do front matter. Monte: node scripts/montar-paginas.mjs (gera blog/[slug].html, dados/posts.json e dados/busca.json; rodar de novo não muda nada).
5. Abra o post por servidor local, em 1440 px e 390 px, e confira texto, capa, legenda e crédito.
6. Atualize o HANDOFF e faça commit e push dos arquivos do post (conteudo/, blog/, assets/img/blog/, dados/posts.json, dados/busca.json e dados/creditos-imagens.json), nunca de textos-blog/.

## 11. Como publicar um em breve

1. Escrever e revisar o texto completo e conferir o crédito/licença da capa.
2. Mover o Markdown de conteudo/blog/em-breve/ para conteudo/blog/, mantendo o slug.
3. Definir em_breve: false, data, autor e subtitulo; gerar também capa-1600.webp no fluxo do conversor para o post completo.
4. Rodar node scripts/montar-paginas.mjs duas vezes; conferir página, relacionados, índice e dobra inicial. Nunca editar dados/posts.json à mão.
5. Testar, atualizar HANDOFF, adicionar só os arquivos da tarefa, commit e push.

## 12. Como atualizar as metas

1. Editar dados/metas.json com os dados aprovados para divulgação; nunca incluir dados de doadores ou movimentações individuais. Atualizar atualizacao (AAAA-MM-DD).
2. arrecadado e meta são números em reais; meta precisa ser maior que zero. Não digitar percentual: a montagem calcula e limita de 0 a 100. Manter exemplo: true enquanto forem dados fictícios.
3. mostrar_valores true publica valores agregados; false omite valores do HTML e mantém percentuais. A escolha aguarda confirmação.
4. Combinar codigo com a tesouraria; esse texto será sugerido na mensagem do PIX, não cria direcionamento bancário automático. Ilustrações disponíveis: banda, infantil, garagem.
5. Chave, titular e QR Code só em dados/igreja.json. Rodar node scripts/montar-paginas.mjs duas vezes, conferir estados/cópia e atualizar HANDOFF antes do commit/push.
